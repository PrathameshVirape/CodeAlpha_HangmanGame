# CodeAlpha Hangman Game

## About the Project
This is a simple text-based Hangman Game developed using Python as part of the CodeAlpha Python Programming Internship.

## Features
- Random word selection from 5 predefined words.
- Six incorrect attempts allowed.
- Displays hidden letters.
- Shows Hangman drawing stages.
- Checks repeated and invalid letter inputs.
- Displays win or game-over messages.

## Technologies Used
- Python
- Random Module

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python hangman_game.py
```
